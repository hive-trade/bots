# HiveTrade example bot setup

Read the repository's [README](../../README.md) and [AGENTS.md](../../AGENTS.md).
If reading this file remotely, fetch those files from the same repository/ref.
Follow those instructions to configure the example, implement the user's own
strategy, test it and preview a dry run. This kit contains public integration
plumbing and educational examples only. No private HiveTrade strategy is needed.
Live trading requires the user's explicit decision and your own financial-action
rules; do not place trades as an implicit setup test.
